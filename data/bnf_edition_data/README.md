# bnf\_edition\_data

The process for querying raw edition data from the BNF SPARQL interface

## data
Zips of the year-wise queried data (bnf\_edition\_data\_raw) and of the data merged into a single data frame (edition\_raw\_data). 

## scripts
The script used to query the SPARQL interface (get\_edition\_data\_raw.R).
