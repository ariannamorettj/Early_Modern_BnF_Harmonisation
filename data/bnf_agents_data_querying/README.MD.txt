# bnf\_agents\_data\_querying

Produces the raw data about the agents (authors, printers etc.) involved in the production of early modern books in the BNF. Required inputs: raw edition metadata (bnf\_data\_raw.csv) of the BNF.

## query\_missing\_agents.R

Script that queries the SPARQL-interface of the BNF for the agent data related to raw edition data.

## actor\_data.zip
Actor data related to all actor types as a single zipped csv.
